АНАЛИТИКА САЙТА → GOOGLE SHEETS / ЛИСТ Analiz

ФАЙЛЫ
1) index_analytics.html — копия исходного index.html с добавленным блоком аналитики. Основная логика сайта сохранена.
2) GoogleAppsScript_Analiz.gs — серверный код для Google Apps Script.

НАСТРОЙКА

ШАГ 1. Создайте скрипт в существующей Google Таблице
1. Откройте Google Таблицу, в которой уже есть лист Analiz.
2. Выберите Расширения → Apps Script.
3. В редакторе откройте файл Code.gs, удалите его содержимое и вставьте весь код из GoogleAppsScript_Analiz.gs.
4. Сохраните проект.
5. В списке функций выберите setupAnalyticsSheet и нажмите Выполнить.
6. При первом запуске подтвердите запрашиваемые Google разрешения. Функция создаст заголовки, если лист пуст. Существующие строки не удаляются.

ШАГ 2. Опубликуйте веб-приложение
1. В Apps Script нажмите Развернуть → Новое развертывание.
2. Тип развертывания: Веб-приложение.
3. Выполнять от имени: Я.
4. У кого есть доступ: Все (Anyone), иначе браузер сайта не сможет отправлять события без входа пользователя в Google.
5. Нажмите Развернуть и скопируйте URL вида:
   https://script.google.com/macros/s/ВАШ_ID/exec
   Не используйте URL редактора /dev.

ШАГ 3. Вставьте URL в HTML
1. Откройте index_analytics.html в редакторе кода.
2. Найдите строку:
   const ANALYTICS_ENDPOINT = 'PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE';
3. Замените значение на URL веб-приложения, сохранив кавычки, например:
   const ANALYTICS_ENDPOINT = 'https://script.google.com/macros/s/ВАШ_ID/exec';
4. Сохраните файл.

ШАГ 4. Опубликуйте на Vercel и Layero
Загрузите обновленный HTML вместо текущего index.html в оба места публикации. Если проект собирается из GitHub на Vercel, замените index.html в репозитории содержимым подготовленного файла и отправьте commit. На Layero загрузите тот же файл. URL Apps Script общий для обеих версий сайта.

ШАГ 5. Проверьте
1. Откройте опубликованный сайт в обычном окне браузера.
2. Перейдите между основными разделами и вкладками.
3. Выберите страну и культуру, выполните поиск объекта, выберите результат, нажмите несколько кнопок.
4. Подождите 5–20 секунд и откройте лист Analiz.
5. Для ручного теста откройте DevTools → Console и выполните:
   window.siteAnalyticsTest()
   Затем проверьте появление строки «Тест аналитики».
6. Если строк нет, проверьте URL ANALYTICS_ENDPOINT, права веб-приложения и ошибки в Console / Apps Script → Выполнения.

ЧТО ЗАПИСЫВАЕТСЯ
Время UTC, дата UTC, страна, код страны, тип события, раздел, вкладка, действие, выбранный объект/поисковый запрос, URL страницы без параметров и фрагмента, источник перехода без параметров, тип устройства, язык браузера, ID сессии.

События: посещение, открытие раздела/вкладки, клики по кнопкам и ссылкам, выбор страны/культуры, изменения фильтров, поиск и выбор объектов, выбор объекта в списке исключений.

ВАЖНЫЕ ОГРАНИЧЕНИЯ И ПРИВАТНОСТЬ
- Страна определяется через внешний сервис ipapi.co. IP-адрес не записывается в Google Таблицу, но сам внешний сервис получает запрос посетителя для определения страны. Если внешний сервис недоступен/ограничил запросы, будет «Не определена».
- Время хранится в UTC; для локального времени можно изменить часовой пояс в коде Apps Script.
- ID сессии хранится только в sessionStorage: он обычно различает отдельные вкладки/сессии, а не является постоянным ID человека.
- Приложение не записывает содержимое произвольных полей форм, но записывает текст поискового запроса после Enter/подтверждения и названия выбранных элементов. Не вводите в эти поля персональные данные.
- Веб-приложение с доступом «Все» является публичным endpoint. Проверка типов событий не защищает от целенаправленного спама. Не используйте этот endpoint для секретных/чувствительных данных и периодически проверяйте лист. Для более строгой защиты потребуется серверный прокси (например, Vercel Function) с ограничением частоты запросов.
- При необходимости посетителей следует уведомить об аналитике и внешнем сервисе геолокации и обеспечить соответствие применимым требованиям о приватности/согласии.
- Чтобы отключить аналитику в браузере, выполните в Console:
  localStorage.setItem('site_analytics_optout','1')
  и перезагрузите страницу. Чтобы включить снова:
  localStorage.removeItem('site_analytics_optout')

Vercel Web Analytics в исходном HTML оставлен без изменений. Дополнительная запись в Google Sheets должна работать как на Vercel, так и на Layero, если они отдают обновленный HTML и endpoint доступен.
